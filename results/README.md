Results will be added here only after the pre-registration freeze (T01, see `../docs/preregistration.md`). Each result file will:

- name the test ID (T01–T48) and the stage it belongs to;
- name the commit and the frozen fingerprint list it was run against;
- record the model actually served (where a model is used), its route and settings;
- report every outcome against the frozen pass/fail criterion, including failures.

Results that were produced after a logged amendment to the criteria will be labelled as such and reported next to, not instead of, the original.
